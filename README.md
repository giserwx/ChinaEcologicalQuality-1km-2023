# 2023年中国1 km生态质量评估网格化数据集

**中文** | [English](README_EN.md)

2023年 · 中国 · 1 km × 1 km · GeoTIFF · 无量纲指数

## 数据集简介

本数据集由首都师范大学胡卓玮教授课题组生产，是国家重点研发计划项目“大尺度生态质量与生态服务评估大数据智能挖掘技术和关键参数网格化平台建设应用示范”课题3（2023YFF1303703）形成的生态质量评估数据产品。

数据集提供2023年中国全国尺度、1 km网格的生态质量指数（NSEQI），采用基于动态分区与稳定本底的生态质量评估方法，融合叶面积指数（LAI）、植被覆盖度（FVC）、总初级生产力（GPP）及历史土地覆盖等数据。

本数据集**可以用于**全国及区域尺度生态质量空间分布分析、生态保护修复研究和典型生态脆弱区域的生态质量现状评估；结合土地利用、保护地及其他研究区资料，也可以为土地利用规划、生态保护修复优先区域识别和生态安全格局研究提供基础数据。

## 数据获取

请在本仓库的 [**Releases**](https://github.com/giserwx/ChinaEcologicalQuality-1km-2023/releases) 页面下载 `China_Ecological_Quality_Index_2023_1km.tif` 和 `SHA256SUMS.txt`。仓库的“Download ZIP”只包含说明、元数据、配图和读取示例，不包含全国GeoTIFF。

下载后可使用 `sha256sum China_Ecological_Quality_Index_2023_1km.tif`（Linux/macOS）或 `Get-FileHash China_Ecological_Quality_Index_2023_1km.tif -Algorithm SHA256`（PowerShell）核对文件完整性。

## 技术方法

本数据集基于中国多时期LAI、FVC、GPP等生态参数，以及2000—2023年土地覆盖数据（MODIS MCD12Q1），采用动态分区与稳定本底相结合的生态质量评估方法。

1. **构建动态评价单元。** 融合国家生态功能区划与动态生态系统类型，构建生态质量评价单元。
2. **识别稳定本底候选区域。** 在评价单元内筛选历史生态系统类型保持一致的区域。
3. **筛选高功能、高稳定性本底。** 采用“多年均值高于90%分位数”与“变异系数低于10%分位数”的双阈值，识别历史稳定生态本底。
4. **优选参照值并开展评估。** 选取本底区域内生态指数的99%分位数作为参照值，形成2023年1 km网格生态质量评估结果。

## 质量评估

课题组将本数据的评价结果与《全国生态状况调查评估技术规范 生态系统质量评估》对应的评价结果进行对比：

| 评估内容 | 结果 |
| --- | --- |
| 与技术规范评价结果的拟合 | R² = 0.8014 |
| 对比研究数据与技术规范评价结果的拟合 | R² = 0.7046 |
| 变异系数（CV） | 技术规范评价结果为0.565，本方法为0.480 |
| 评价结果不确定性相对降幅 | 15% |

## 读取数据

可使用支持GeoTIFF的GIS软件打开文件，或安装Python的`rasterio`和`numpy`后运行：

```bash
python scripts/read_geotiff.py /path/to/China_Ecological_Quality_Index_2023_1km.tif
```

本仓库仅提供2023年数据。开展变化趋势或修复成效分析时，需要结合可比年份数据及相关研究资料。
